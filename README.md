## 設計

視覺語言依《こども本の森 中之島 UI 設計準則 v1.0》：紙色底 `#F3EFE4`、森林綠 `#62A968`
（小字綠用 `#2E5339` 以達 WCAG AA）、Huninn ＋ Varela Round 圓體、膠囊標籤、8 的倍數間距、
fade-in-up 進場並尊重 `prefers-reduced-motion`。
